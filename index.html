Products & Systems

DTA Automated Inspection System

Software Engineer @ SkillReal (2025–Present)

An inference-based quality inspection system installed at the end of an automotive production line. Cameras capture each part from multiple angles and, when needed, across several stages. The system compares those captures with a master backed by a 3D CAD model, checks configured features such as welds, seams, and pores, and returns a pass/fail result to the factory line.

c# unity python mongodb plc zmq industrial-automation ci/cd observability

GaitBetter Rehabilitation Platform

Software Engineer @ GaitBetter (2022–2024)

A physiotherapy system for older adults and people with conditions such as Parkinson’s disease. A low-end computer, TV, Intel RealSense camera, and two physical buttons are mounted to a treadmill. Patients move through engaging, gamified cognitive scenarios while walking, combining physical movement with decision-making tasks to improve their motor-cognitive reserve.

c# unity .net core distributed-systems sqlite computer-vision hardware-integration rest-api

VR Training Simulators

Software Engineer @ 3D Systems (2019–2021)

Training products built around bringing physical equipment into VR with accurate tracking. The combat simulator supports one-to-four-player missions using wireless HTC Vive Pro backpacks and tracked M4 training rifles with working trigger and magazine inputs. Trauma VR uses a tracked medical mannequin so trainees can assess an unconscious patient, clear an airway, check vital signs, and practise procedures with physical tools.

c# unity vr motion-tracking hardware-integration networking
